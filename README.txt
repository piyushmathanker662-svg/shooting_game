KISS HUNTER — simple romantic shooting game

HOW TO USE
1. Extract this ZIP.
2. Open index.html in a browser to test.
3. Replace piyush.svg with your photo and afsar.svg with Afsar's photo (or edit the img src names in index.html).
   Recommended: square JPG images. If using JPG, change:
   - src="piyush.svg" to src="piyush.jpg"
   - src="afsar.svg" to src="afsar.jpg"
4. Upload all files together to a GitHub repository.
5. In GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.

GAMEPLAY
- Afsar is the shooter at the bottom.
- Your photo appears as the target in the arena.
- Tap/click the target to shoot.
- Each hit adds 1 kiss, the target disappears, then respawns at a random position after 1 second.
- Tap elsewhere to miss.

Files:
index.html, style.css, script.js, piyush.svg, afsar.svg
